# 修改后项目使用指南

## 新程序位置

修改后的程序已编译并保存在 `bin/` 目录中：

- **球体渲染程序**：`bin/sphere_new.exe`
- **太阳系模拟器**：`bin/solar_system_new.exe`

## 运行程序

### 方式一：直接运行
在 `bin/` 目录中双击相应的 `.exe` 文件即可运行。

### 方式二：命令行运行
```bash
cd bin
./sphere_new.exe          # 运行球体程序
./solar_system_new.exe    # 运行太阳系程序
```

## 程序功能

### 球体渲染程序 (sphere_new.exe)
一个交互式的 3D 球体网格渲染程序，支持：
- 多种渲染模式（点、线、面）
- 实时交互（旋转、平移、缩放）
- 纹理映射和光照效果
- 阴影渲染

### 太阳系模拟器 (solar_system_new.exe)
一个逼真的太阳系模拟程序，包含：
- 8 大行星的运动模拟
- 月球绕地球运动
- 土星环的渲染
- 星空背景
- 行星轨道线显示

## 交互控制

### 鼠标操作
- **左键拖动**：旋转视图
- **右键/中键拖动**：平移视图
- **滚轮**：缩放视图
- **左键点击**：选择/取消选择对象

### 键盘操作
- **Q/W**：设置几何变换的起点和终点
- **T**：切换纹理显示
- **S**：切换阴影显示
- **0-2**：切换渲染模式（点/线/面）
- **ESC**：退出程序

修改后的程序具有以下视觉特色：

## 故障排除

### 程序无法运行
- 确保 `glfw3.dll` 在 `bin/` 目录中
- 确保 `lib/` 目录中的库文件完整
- 检查显卡驱动是否支持 OpenGL

### 纹理无法加载
- 确保所有 `.bmp` 文件在 `bin/` 目录中
- 检查文件名是否正确（区分大小写）

### 性能问题
- 降低球体网格分辨率（修改 SphereMesh 参数）
- 关闭纹理和阴影以提高性能
